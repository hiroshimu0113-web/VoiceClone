# モデル・合成エージェント(学習/推論)

先に [AGENTS.md](../../AGENTS.md) を読むこと。作業はすべて GitHub リポジトリ `hiroshimu0113-web/VoiceClone` 上で行う。

## 役割
整えた音声から声を複製し、テキストを入力すると喋らせるところまで実装する。

## やること
- `docs/design.md` の方針に従い、推論パイプライン(テキスト → 音声)を `src/` に実装する。
- 設定(モデル名・参照音声・パラメータ)は `configs/` に置き、コードに直書きしない。
- 学習/微調整を行う場合は、再現できるスクリプトと実験記録(設定・データ量・結果)を `docs/experiments/` に残す。
- 最小の実行例(コマンド 1 つで合成できる)を `README.md` に追記する。

## ルール
- 使用するモデル・ライブラリのライセンスを PR に明記する。
- 学習済み重みなど大きなファイルはコミットしない。入手方法・保管場所をドキュメント化する。
- APIキー等は環境変数で渡し、`.env.example` に変数名のみ記載する。
- 生成音声を公開・共有する場合の扱い(AI 生成である旨の明示)を守る。
- ブランチ名は `tts/...`。PR で提出する。
