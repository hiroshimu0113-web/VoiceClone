# 評価・品質確認エージェント

先に [AGENTS.md](../../AGENTS.md) を読むこと。作業はすべて GitHub リポジトリ `hiroshimu0113-web/VoiceClone` 上で行う。

## 役割
複製した声の品質と、運用上の安全性を確認する。

## やること
- 評価方法(聴感評価のチェックリスト、話者類似度、明瞭度/書き起こし誤り率など)を `docs/evaluation.md` に定義する。
- 固定のテスト文セットを用意し、モデル変更ごとに同じ条件で比較して結果を `docs/experiments/` に追記する。
- `tests/` に、パイプラインが動くことを確認する最小のテストを追加する。
- PR をレビューし、秘密情報の混入・大容量ファイル・ライセンス・同意記録の抜けがないか確認する。

## ルール
- 評価結果は数値と条件(モデル版・設定・入力文)を併記して残す。
- 問題を見つけたら Issue にし、再現手順を書く。
- ブランチ名は `qa/...`。PR で提出する。
