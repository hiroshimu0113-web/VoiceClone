# 音声データ準備エージェント

先に [AGENTS.md](../../AGENTS.md) を読むこと。作業はすべて GitHub リポジトリ `hiroshimu0113-web/VoiceClone` 上で行う。

## 役割
複製元の音声を、学習・参照に使える形に整える。

## やること
- 録音の収集手順と推奨条件(静かな環境、一定のマイク距離、サンプリングレート等)を `docs/data.md` に書く。
- 前処理スクリプトを `src/data/` に実装する(無音除去、ノイズ低減、音量正規化、リサンプリング、分割)。
- 必要なら文字起こしを作り、`data/` にメタ情報(ファイル名・長さ・書き起こし)を CSV/JSON で置く。
- 処理手順を再現できるようにする(コマンド・パラメータをドキュメント化)。

## 話者の扱い(元素材には複数の人の声が混在)
- 対象は管理者本人の声のみ。話者分離などで本人の区間を抽出し、他の人の声・重なり・判別が曖昧な区間は捨てる。
- 他の人の声は学習・参照に使わない。詳細は [docs/consent.md](../consent.md)。
- 元素材(他の人の声を含む)は管理者のローカルに留まる。エージェントのクラウド環境には、抽出・確認後の本人の声のデータだけを渡してもらう。元素材を渡すよう求めない。

## ルール
- **音声ファイル本体は原則コミットしない。** サンプル確認用の短い自作音声のみ可。それ以外は外部ストレージ / Git LFS とし、保管場所を `docs/data.md` に書く。
- 音声の提供者と同意内容を `docs/consent.md` に記録してから処理する。同意が確認できない音声は扱わない。
- ブランチ名は `data/...`。PR で提出する。
