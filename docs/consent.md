# 音声の同意と取り扱い記録

## 複製の対象
- **複製対象は、プロジェクト管理者(リポジトリ所有者)本人の声のみ。**
- 目的: 自分の声をボイスとして喋らせる。

## 元素材
- 保管場所: ローカル専用フォルダ(`docs/security.md` 参照)。リポジトリには置かない。
- 内容: 管理者本人の声に加え、**複数の他の人の声が混在している**。

## 他の人の声の扱い(方針)
1. 他の人の声は**複製・学習・参照に使わない**。
2. 処理は、本人の声の区間だけを取り出す方式にする。他の人の声が重なる区間・判別が曖昧な区間は**捨てる**(確実に本人だけの区間のみ採用)。
3. 取り出した本人の声のデータにも、他の人の声が小さく混ざっていないか確認する(`qa` が確認)。
4. 他の人の声を含む元素材は、ローカルに留める。Claude やクラウドに渡さない。抽出後の不要な元素材の扱い(削除する/保管する)は管理者が決め、下に記録する。
5. 他の人の声・会話内容を、ドキュメント・Issue・PR・ログに書き写さない(書き起こしを作る場合も、本人の発話のみ)。
6. その人たちの声を、第三者に提供しない。

## 生成音声の利用
- 生成した音声は AI による合成であることを明示する。
- 本人以外の声に似せる用途、なりすまし、詐欺、偽情報には使わない。
